# React Native Todo App  " TASKLY "

A clean and responsive **Todo Management App** built with React Native, focused on mobile UI/UX, usability, and task management.

## ✨ Features

* 🔐 User Sign Up & Login
* ☁️ Cloud-based task synchronization
* ➕ Create new tasks
* ✏️ Edit existing tasks
* ✅ Mark tasks as completed
* 🗑️ Delete tasks
* 📋 View pending and completed tasks
* 📱 Responsive mobile-first UI
* 🔄 Real-time task synchronization
* 🔒 User-specific task data

## 🛠️ Tech Stack

* **React Native** – Mobile application
* **JavaScript / TypeScript** – Application logic
* **Node.js** – Backend
* **REST API** – Client-server communication

## 📱 Screens

The application includes:

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Roshan3300/Taskly
cd <PROJECT_FOLDER>
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the Metro server

```bash
npm start
```

### 4. Run on Android

```bash
npx react-native run-android
```

## 🔧 Configuration

If the project uses a backend API, configure the API base URL in the appropriate environment/configuration file.
